# Words — 英コミ定期テスト対策

添付の単語・熟語・構文一覧をもとにした、GitHub Pages向けの静的学習アプリです。Phase 1〜7を実装し、641語句の学習、詳細分析、SIMPLE／MAX演出、PWA・オフライン利用まで対応しています。

## 使い方

静的ファイルだけで動作します。ローカル確認ではリポジトリ直下をHTTPサーバーで配信してください。

```sh
python -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。GitHub Pagesではリポジトリ直下の `index.html` がそのまま配信されます。

## 実装済み

- 全641語句（単語383・熟語197・構文61）と、重要度・難易度・範囲・複数出典
- 英語→日本語4択、日本語→英語4択、日本語→英語入力
- スペル完全入力、前置詞穴埋め、熟語・構文穴埋め
- 日本語→英語入力で、解答の単語数と同じ数の入力四角
- 「学習を始める」から、単語／熟語／構文／すべて、4択／記述を順番に選ぶ段階式フロー
- 熟語・構文の記述では、一部の穴埋め／英語を全部書く、を選択可能
- 構文の日本語4択では文法注記を隠し、直近12問を除いた異なる範囲から誤答候補を選択
- 学習範囲は「全範囲／その他」、重要度は「重要度全部／その他」から段階的に選び、その他では複数選択可能
- 並び替えは「重要度順／難易度順／苦手順／その他」のボタンから選び、形式・絞り込みの確認画面を省略してスタート
- 熟語・構文の穴埋め問題に日本語訳を表示
- 教材・出題方法・記述範囲の組み合わせごとに正誤と回答位置を保存し、次回は続きから再開
- 学習中にアプリを閉じた場合、次回のホームに「途中から」と組み合わせ・回答位置を表示
- 「途中から」はホーム画面の最上部に表示
- 組み合わせの1周目は成績条件なし、2周目は一度でも間違えた問題、3周目以降は成績条件を選択必須
- 学習の絞り込みは範囲・重要度・周回別成績に整理し、種類・タグ条件を廃止
- IndexedDB保存とlocalStorageフォールバック
- 項目・出題形式ごとの正解数、不正解数、連続正解、回答日時
- 範囲、重要度、成績、ミス回数の複合絞り込み
- 難易度順・苦手順を含む18種類の並び替え
- 学習設定の初期並び替えは重要度が高い順
- 全641語句のうち現在2回以上連続正解している語句の割合、回答時間、範囲別成績、誤答語句を表示する詳細リザルト
- 全体・8範囲・6形式の学習分析
- 形式選択、単語帳、回答フィードバック、リザルト、分析でのタグ表示
- Apple純正アプリに近いSIMPLE UIと、iPhone・iPad・PC向けレスポンシブ表示
- 初回起動時のSIMPLE／MAX選択と、後から変更できる設定画面
- MAX MODEのCanvasパーティクル、コンボ、画面シェイク、効果音・振動の個別設定
- `CORRECT`、3／5／10／20／30コンボ、`PERFECT`、`SSS MASTER`、`WEAKNESS DESTROYED`、`NEW RECORD`演出
- `prefers-reduced-motion`と低性能端末を考慮した演出量の自動抑制
- Web App Manifest、Service Worker、ホーム画面追加、読み込み後のオフライン利用
- Dynamic Island／Home Indicatorを考慮したセーフエリアと44px以上のタップ領域
- 回答後は正解選択肢・範囲を一画面に表示し、固定ボタンまたは画面タップで次へ進行

## テスト

Node.js 22以降で次を実行します。

```sh
npm test
```

教材データの件数・必須項目・出題形式を検証した後、回答判定、履歴、複合フィルター、苦手順、選択肢、セッション構築、2回連続正解率を含む集計をテストします。

## 教材データの再生成

`tools/import_xlsx.py` は元Excelの `全一覧_重要度順` シートから `data/items.json` を生成します。Excel内の同一英語は1項目に統合し、すべての出典と異なる日本語訳を保持します。Python 3とopenpyxlが必要です。

```sh
python tools/import_xlsx.py path/to/source.xlsx data/items.json
```
