# Words — 英コミ定期テスト対策

添付の単語・熟語帳をもとにした、GitHub Pages向けの静的学習アプリです。Phase 1〜3として、423語句の一覧、6つの出題形式、IndexedDB学習履歴、複合フィルター、並び替え、苦手順、クイック学習まで実装しています。

## 使い方

静的ファイルだけで動作します。ローカル確認ではリポジトリ直下をHTTPサーバーで配信してください。

```sh
python -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。GitHub Pagesではリポジトリ直下の `index.html` がそのまま配信されます。

## 実装済み

- 全423語句と、重要度・範囲・複数出典
- 英語→日本語4択、日本語→英語4択、日本語→英語入力
- スペル完全入力、前置詞穴埋め、熟語・構文穴埋め
- 日本語→英語入力で、解答の単語数と同じ数の入力四角
- IndexedDB保存とlocalStorageフォールバック
- 項目・出題形式ごとの正解数、不正解数、連続正解、回答日時
- 範囲、重要度、種類、成績、ミス回数、形式、タグの複合絞り込み
- 苦手順を含む17種類の並び替え
- 苦手、間違い、SSS、前回の続き、おすすめ、ランダム、前置詞、スペルのクイック学習

## テスト

Node.js 22以降で次を実行します。

```sh
npm test
```

教材データの件数・必須項目・出題形式を検証した後、回答判定、履歴、複合フィルター、苦手順、選択肢、セッション構築をテストします。

## 教材データの再生成

`tools/import_xlsx.py` は元Excelの `全一覧_重要度順` シートから `data/items.json` を生成します。Python 3とopenpyxlが必要です。

```sh
python tools/import_xlsx.py path/to/source.xlsx data/items.json
```
