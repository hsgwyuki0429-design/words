# Words — 英語・古文・公共・保健 定期テスト対策

古文を独立教科として追加しました。助動詞28種類を、接続・全意味選択・活用表の埋める式／タイプ式・活用形から基本形の5形式で学習できます。活用なしの「○」、複数形・複数正解、形式別履歴と中断後の再開に対応します。古文単語は教材待ちです。データの訂正根拠と拡張方法は [古文の実装説明](docs/kobun.md) を参照してください。

英語1,314語句、公共291問、保健282問を収録した、GitHub Pages向けの静的学習アプリです。2026.2の教科選択、詳細分析、SIMPLE／MAX演出、PWA・オフライン利用まで対応しています。

## 2026.2の教科

- 初回だけ「2026.2」を選び、2回目以降は自動で教科選択へ進みます。
- 英語は単語／熟語／語法を、英語→日本語または日本語→英語の4択／フラッシュカードに加え、日本語を見て英語を答えるキーボード入力で学習できます。
- 公共は一語一答版の語句回答291問（S130・A131・B22・C8）を収録しています。答えは用語・人物名・制度名・法令名・地名など1項目に統一し、短文回答・複数回答・年代数値回答は収録していません。カードはタップで問題面と答え面を切り替え、答え面を左（3分後）／右（1時間後）／上（習得）へスワイプして自己採点します。
- 保健は一語一答版の語句回答282問（S127・A96・B48・C11）を収録し、公共と同じ自己採点方式で学習できます。答えは用語・固有名詞・略称・数値など1項目に統一し、本文だけでなく図・表・欄外・Columnからも出題します。
- 全教科で範囲、重要度、回答状況を絞り込み、重要度順／苦手順／ランダム／その他から並び替えられます。
- 4択とキーボード入力で間違えた問題は自動で3分後の出題待ちへ入り、自己採点では3分後または1時間後を選べます。
- 公共の下部ナビ「重要語句」には、重要語句完全網羅文章（`public-notes.html`）をそのまま表示します。
- 保健の下部ナビには要点まとめ・知識つながりノートを表示し、画面下半分の赤シートで赤橙色の暗記語句と下線を隠せます。

## 使い方

静的ファイルだけで動作します。ローカル確認ではリポジトリ直下をHTTPサーバーで配信してください。

```sh
python -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。GitHub Pagesではリポジトリ直下の `index.html` がそのまま配信されます。

## 実装済み

- 添付監査版に基づく全1,314語句（原形別単語903・熟語331・語法80）と、重要度・難易度・範囲・複数出典
- 単語は重要度B以上を原形で統合し、本文中の活用形・表記も表示
- 訳に答えの英語がそのまま出ている語句は、注記を削るか出題対象から除外（人名・固有名詞の断片27語を除外、12語の訳を修正）
- `help A (to) do`／`help A do`のような同じ語法の書き分けは1件に統合し、訳・用例・出典をまとめて保持
- 穴埋めは括弧を跨いで区切らず、`help A (to) ___`のように任意扱いの語を残したまま出題
- 英語→日本語と日本語→英語の4択・フラッシュカード、および日本語→英語のキーボード入力
- キーボード入力は英語の単語数に合わせた折り返し可能な入力欄を使い、スペース／次へ／完了、空欄でのBackspace、熟語の貼り付け配分に対応
- キーボード入力中は「文字数：非表示／表示」を切り替えられ、表示時だけ各語の文字数をアンダーバーで確認可能。設定は端末へ保存
- `(to)`などの任意語、`good/better`の別表記、構文中の固定記号を入力用表記へ展開し、教材の`acceptedAnswers`と共通の正規化で判定
- ホーム＝学習ダッシュボード。範囲名だけを並べた一覧 → 範囲をタップ → 5形式の進捗カード → 学習内容 → 重要度 → 並び替え → 学習、という一続きの導線
- 範囲一覧は2カラム。先頭に他のボタン2個分の横幅（高さは同じ）の「全範囲」を置き、全範囲をまとめて学習できる
- 範囲一覧・形式カード・学習内容・重要度・並び替えはいずれも iPhone 縦画面でスクロールなしに全項目が収まる高さ。選択画面の見出しは戻るボタンとタイトルを1行にまとめ、safe-area（Dynamic Island・ホームインジケータ）を差し引いた実機の高さで検証している
- 画面が低い端末（iPhone SE など）では `@media (max-height: 720px)` で余白と文字サイズだけ詰め、タップ領域は44px以上を維持
- 学習内容は「単語／熟語／構文／全選択」を1タップで確定して次へ進み、「その他」を押したときだけ複数選択画面を開く
- 重要度は「全重要度」を先頭に置いた1列リストで毎回選び、1タップで確定。「その他」からは複数選択もできる
- 並び替えも学習内容と同じ1列リストで「重要度順・難易度順・苦手順・ランダム」を並べ、押した時点で学習開始。詳細な並び順は「その他」へ退避
- 重要度順・難易度順では、同じレベル帯の中（S の中、F の中など）の並びを毎回ランダムにする。レベルをまたぐ順番は変えない
- 範囲一覧の最下部に「複数の範囲を選ぶ」を用意し、既存の複数範囲選択画面から確定するとその範囲の形式別進捗へ進む
- 形式カードを押した時点で範囲と出題形式が確定し、範囲・出題方向・形式を聞き直さない
- 「条件学習」からは従来の段階式フロー（範囲→学習内容→出題方向→問題形式→重要度→並び替え）も利用可能
- 英語フラッシュカードも公共・保健と同じく、タップで問題面と答え面を何度でも切り替え、答え面の左／右／上スワイプで自己採点
- 4択・キーボード入力・フラッシュカードの未回答・間違えた語句・正答率は、形式ごとに分けて集計
- ダッシュボード下部には最近使った学習条件を最大4件表示し、教科・範囲・教材・出題形式・絞り込みを確認してワンタップで再開
- 語法の日本語4択では文法注記を隠し、直近12問を除いた異なる範囲から誤答候補を選択
- 熟語・語法にA・Bが含まれる4択では、A・Bの個数が同じ誤答候補を使用
- 日本語→英語の4択では、問題文と同じ訳を持つ語句を誤答候補から除外（`ごみ`に`garbage`と`trash`が並ばない）
- すべての4択問題に「わからない」を表示
- 4択とキーボード入力は回答後のカードを上下左右どの方向へ払っても次へ進行
- スワイプ中はカードが指へ追従し、現在カードの退場中に次カードが反対方向から重なって登場
- 10pxのtap許容、距離／速度のswipe判定、キャンセル復帰、遷移ロック、synthetic click抑止を共通gesture処理で管理
- 英語（単語・熟語・構文）をブラウザ標準のWeb Speech APIで自動再生。答えを先に聞かせないよう、読み上げどきは出題方向で分ける
  - 英語→日本語（4択・フラッシュカード）：問題を開いたときに問題の英語
  - 日本語→英語（4択・キーボード入力）：解答して答えが出たときに答えの英語
  - 日本語→英語（フラッシュカード）：答え面を開いたときに答えの英語
- 読み上げは画面に出している`question`と同じデータを使うので、表示と音声がずれない。判定は`englishSpeechTiming()`の1か所にまとめる
- 英語→日本語の最初の1回は「学習開始」のタップから同期でつながる（`beginSession()` → `prepareQuestion()`）。日本語→英語も解答・答え表示のタップから同期でつながるため、ユーザー操作を必要とするiOS Safariでも再生できる。読み上げ専用のボタンや画面は増やしていない
- 2問目以降は既存のスワイプがそのままきっかけになる。次へ進むと確定した時点（`handleRecallSwipe` / `handleChoiceNextSwipe`）で再生中の音声を止め、次の問題へ引き継ぐ。途中で戻したスワイプでは何も再生しない
- 速く連続でスワイプしても、読み上げの直前に必ず`speechSynthesis.cancel()`を入れるため音声がキューに溜まらず、つねに最新の問題だけが読まれる
- 声は`en-US`を優先して自動選択し、無ければ他の英語の声、それも無ければ`lang`指定だけでOS標準に任せる（`Samantha`や`Google US English`のような特定の声名には依存しない）。`voiceschanged`は購読するが待ち合わせないので出題やスワイプは遅くならない
- 括弧・併記・`+`・日本語の注記は読み上げ用にだけ整える（`help A (to) do`→`help A to do`、`be good/better at doing`→`be good, better at doing`、`make A + 動詞原形`→`make A`）。熟語・構文は分割せず一続きで読む
- 読み上げの速さは設定の「学習画面」から×0.5・×0.75・×1.0・×1.25・×1.5の5段階で選べる（既定は×1.0＝各ブラウザの標準速度）。選んだ速さはその場で見本を読んで確かめられ、端末へ保存される
- Web Speech APIが無い・使えないブラウザでは黙って読み上げないだけで、出題・スワイプ・正誤判定・学習記録はすべてそのまま動く。公共・保健の一問一答は読み上げ対象外
- 学習範囲は全教科で最初にコンパクトな一覧から複数選択でき、「全選択」時は個別範囲を無効化
- 英語の教材は単語・熟語・語法を複数選択でき、「全選択」からまとめて選択可能
- 並び替えは「重要度順／難易度順／苦手順／ランダム／その他」から選び、全問をそのままスタート
- 形式カード・「何を学習しますか？」・重要度の各ボタンに、同じ集計（`summarizeRangeModeProgress`）による同じ進捗ゲージを表示。学習内容は「その形式 × その内容」、重要度は「その形式 × 選択中の内容 × その重要度」で絞り込む
- 各形式カードは1本の横長ゲージで「範囲の学習対象語句数（未回答＝背景）」「その形式で1回以上回答した語句（薄い塗り）」「現在の習得ラウンドで習得した語句（濃い塗り）」の包含関係と、周回の現在地を表示
- ゲージの分母はその形式で実際に出題できる項目数。回答済み判定は`modeStats[形式].attempts > 0`で、形式ごとに完全に分離
- 周回ごとに積むバーは最大2本（終えた周回1本＋現在の周回1本）。終えた周回は古いほうから1本に畳み、何周目かは凡例の「N周目」で示す。2周目でも400周目でもカードの高さは同じで、選択画面は1画面に収まったまま
- ゲージの表示値は`summarizeProgressGauge()`が整える。分母を超える件数、負数・NaN・欠損、壊れた周回番号のいずれが保存されていても、幅は必ず0〜100%に収まり「未回答 ⊇ 解答済み ⊇ 習得」の包含関係が崩れない
- 習得判定は`evaluateMastery()`の1か所に集約し、周回状態（`firstAttemptResults` / `consecutiveCorrect`）から求める
- 「解答済み」は長期履歴で基本的に減らない。「習得」は新しい習得ラウンドが始まると0から数え直す
- 数値は必ず意味付きで表示（`解答済み 68%（68 / 100語句）`）。範囲一覧には割合を一切表示しない
- 出題対象は周回エンジンが自動決定するため、通常フローに「回答状況を選ぶ」画面はない
- 1周目は条件に合う全問題が対象。対象すべてがその周回で最低1回正解するまで周回は終わらない
- 途中で閉じても、その周回でまだ正解していない問題（3分後・1時間後の再出題待ちを含む）だけを再開対象にする
- n周目の対象は n-1周目終了時点で未習得の問題。すべて習得すると新しい習得ラウンドを全問題から開始する（長期履歴は保持）
- 周回状態は「教科・範囲・学習内容・正確な出題形式・重要度などの絞り込み」の組み合わせごとに保存。並び替えを変えても同じ周回のまま
- 既定の習得条件は「その周回の最初の回答で正解」。初手で間違えた問題は同じ周回で正解しても未習得のまま次の周回へ回る
- 設定の「学習状況・周回」から習得条件を「その周回の最初の回答で正解」／「2回連続で正解（同一形式のみ）」に切り替え可能。変更時は周回・習得状態だけを新ラウンドとしてやり直す
- 学習画面と結果画面から「1つ前の回答に戻る」で直前1件を取り消し、履歴・周回・習得・再出題予約・コンボを回答直前の状態へ復元
- 同じ範囲・重要度に回答履歴があれば未回答を先頭にし、未回答がなくなると未回答を隠して復習を先頭に表示
- 学習の絞り込みは範囲・重要度・回答状況に整理し、種類・タグ条件を廃止
- IndexedDB保存とlocalStorageフォールバック
- 項目・出題形式ごとの正解数、不正解数、連続正解（形式別と全形式の両方）、回答日時
- 周回・習得状態（`studyProgress`）を組み合わせキーごとに保存し、アプリを閉じても同じ周回から再開
- 範囲、重要度、成績、ミス回数の複合絞り込み
- 苦手順・難易度順・正答率順などの詳細な並び替え
- 学習設定の初期並び替えは重要度が高い順
- 学習終了後は学習ダッシュボードへ戻り、上部に今回の結果（教科・範囲・教材・形式、正解／間違い、学習時間、要確認問題）、下部に次の学習範囲を並べて表示
- 結果から間違いだけの再挑戦、同じ条件でもう一周、学習条件の変更、詳しい分析へ移動可能
- 全体・8範囲・6形式の詳細な学習分析は分析タブに継続して用意
- 形式選択、単語帳、回答フィードバック、リザルト、分析でのタグ表示
- Apple純正アプリに近いSIMPLE UIと、iPhone・iPad・PC向けレスポンシブ表示
- 初回起動時のSIMPLE／MAX選択と、後から変更できる設定画面
- MAX MODEの単一Canvasタイムライン、コンボ、画面シェイク、Web Audio効果音・振動の個別設定
- `CORRECT`、3／5／10／20／30コンボ、`PERFECT`、`SSS MASTER`、`WEAKNESS DESTROYED`、`NEW RECORD`を音・光・文字・振動で同期する固有演出
- Cメジャー・ペンタトニックに沿ってコンボごとに音程と厚みが上がるオリジナル合成音、マスター圧縮、ボイス数制限、控えめ／フル設定
- `prefers-reduced-motion`と低性能端末を考慮した演出量の自動抑制
- Web App Manifest、Service Worker、ホーム画面追加、読み込み後のオフライン利用
- Dynamic Island／Home Indicatorを考慮したセーフエリアと44px以上のタップ領域
- 回答後は正解選択肢・範囲を一画面に表示し、4択はカードスワイプ、入力式は固定ボタンで次へ進行

## 教材データの再生成

`tools/import_xlsx.py` は監査版Excelの `02_英単語一覧`、`03_熟語・連語一覧`、`04_語法一覧` から `data/items.json` を生成します。単語は重要度B以上を原形単位で、熟語・語法は同一英語単位（任意扱いの括弧と`/`併記を除いて同じものは1件）で統合し、本文中の形・用例・すべての出典を保持します。訳に答えの英語がまるごと出ている場合は、その注記を削り、削った結果が「人名」「〜の一部」のようなラベルだけになる語句は出題対象から外します。従来の `全一覧_重要度順` 形式にも対応しています。Python 3とopenpyxlが必要です。

```sh
python tools/import_xlsx.py path/to/source.xlsx data/items.json
```
