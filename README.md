# Words — 英コミ定期テスト対策

添付の単語・熟語帳をもとにした、GitHub Pages向けの静的学習アプリです。Phase 1〜4として、423語句の一覧、6つの出題形式、IndexedDB学習履歴、複合フィルター、詳細リザルト、学習分析、自動おすすめまで実装しています。

## 使い方

静的ファイルだけで動作します。ローカル確認ではリポジトリ直下をHTTPサーバーで配信してください。

```sh
python -m http.server 8000
```

その後 `http://localhost:8000/` を開きます。GitHub Pagesではリポジトリ直下の `index.html` がそのまま配信されます。

## 実装済み

- 全423語句と、重要度・範囲・複数出典
- 英語→日本語4択、日本語→英語4択、日本語→英語入力
- スペル完全入力、前置詞穴埋め、熟語・構文穴埋め
- 日本語→英語入力で、解答の単語数と同じ数の入力四角
- 「学習を始める」から、単語／熟語・構文／両方、4択／記述を順番に選ぶ段階式フロー
- 熟語・構文の記述では、一部の穴埋め／英語を全部書く、を選択可能
- 熟語・構文の穴埋め問題に日本語訳を表示
- 教材・出題方法・記述範囲の組み合わせごとに正誤と回答位置を保存し、次回は続きから再開
- IndexedDB保存とlocalStorageフォールバック
- 項目・出題形式ごとの正解数、不正解数、連続正解、回答日時
- 範囲、重要度、種類、成績、ミス回数、タグの複合絞り込み
- 苦手順を含む17種類の並び替え
- 学習設定の初期並び替えは重要度が高い順
- 苦手、間違い、SSS、前回の続き、おすすめ、ランダム、前置詞、スペルのクイック学習
- 正答率、連続正解、回答時間、範囲別成績、誤答語句を表示する詳細リザルト
- 全体・8範囲・6形式の学習分析と、履歴・重要度・直近ミスに基づくおすすめ15問
- 形式選択、単語帳、回答フィードバック、リザルト、分析でのタグ表示

## テスト

Node.js 22以降で次を実行します。

```sh
npm test
```

教材データの件数・必須項目・出題形式を検証した後、回答判定、履歴、複合フィルター、苦手順、選択肢、セッション構築、Phase 4集計、おすすめ生成をテストします。

## 教材データの再生成

`tools/import_xlsx.py` は元Excelの `全一覧_重要度順` シートから `data/items.json` を生成します。Python 3とopenpyxlが必要です。

```sh
python tools/import_xlsx.py path/to/source.xlsx data/items.json
```
