# 古文単語（本文中の重要語句）

定期テスト範囲の7作品（伊勢物語3編・徒然草2編・羅生門・今昔物語集）から抜き出した
重要語句360語句を、英語のフラッシュカードと同じ自己採点カードで学習します。

入口は古文のトップにある「古文単語」です。押すと `kobun-vocabulary` イベントで
英語・公共・保健と共通の学習画面（範囲 → 重要度 → 並び替え → カード）へ渡します。
出題の作り方としては `public` / `health` と同じ「自己採点カード」の仲間で、
`subject: "kobun-vocab"`、出題形式は `kobun-vocab_recall` の1つだけです。
英語のような4択・キーボード入力は作りません。助動詞（`category: "auxiliary"`）は
これまでどおり古文の専用画面で学習します。

## カードの表と裏

| 面 | 出すもの |
| --- | --- |
| 表 | 本文中の短い用例。問われている語句にアンダーラインを引き、必要ならふりがなを振る |
| 裏 | 表の用例に加えて、本文中での意味・覚えるポイント・範囲（作品名） |

タップで表裏を何度でも切り替え、答え面を左（3分後）／右（1時間後）／上（習得）へ
スワイプして自己採点します。ここは公共・保健とまったく同じ操作です。

カードの大きさは公共・保健と同じまま固定し（`height: min(620px, max(64dvh, 100dvh - 176px))`）、
文字量が多いカードは文字だけを縮めます。段階は `vocabCardDensity` が
`roomy` / `normal` / `dense` / `compact` の4つから選び、CSSの `--vocab-scale`
（1／0.88／0.75／0.63）が用例・意味・ポイントの文字サイズと縦の余白にかかります。
表と裏では入る文字数が違うので、いま出している面の文字量で段階を決めます。
描画したあとに `fitVocabCard` が実物のはみ出しを測り、収まるまで倍率を0.05ずつ
（0.55まで）下げます。360語句すべてを iPhone SE（375×667）と iPhone 15 Pro（390×844）
で確認し、どちらもはみ出しはありません。

**難易度は設定していません。** 教材に難易度の指定がないため、全語句の `difficulty` は
`"—"` で固定し、並び替えの選択肢からも「難易度順」を外しています（重要度順・苦手順・
ランダム・その他は使えます）。重要度は教材どおりS・A・B・C・Dの5段階です。

## アンダーラインとふりがな

用例のどこに線を引くか、どの漢字にふりがなを振るかは、教材づくりの時点で決めて
`exampleLines` に保存します。画面側は保存された区間を組み立てるだけです。

```json
{
  "term": "率て行きければ",
  "reading": "ゐてゆきければ",
  "example": "芥川といふ川を率て行きければ",
  "exampleLines": [{ "parts": [
    { "text": "芥川といふ川を", "mark": false },
    { "text": "率", "mark": true, "reading": "ゐ" },
    { "text": "て", "mark": true },
    { "text": "行", "mark": true, "reading": "ゆ" },
    { "text": "きければ", "mark": true }
  ] }],
  "termMarked": true
}
```

- `mark` が `true` の区間にアンダーラインを引きます。隣り合う区間の線はつながります。
- ふりがなは「読み」を手がかりに漢字のかたまりへ割り当てます。送り仮名には振りません。
  漢字と送り仮名が混ざっていて割り当てられない語句（「三河の国」＝「みかは」のように
  読みが一部しか書かれていないもの）はふりがなを付けません。
- 用例が「／」で並記されている語句は、用例ごとに1行として持ちます。
- 教科書と表記が違うなどで用例の中に語句が見つからない3語句（勇気・にきび・飢饉）は
  `termMarked` が `false` になり、表に語句そのものを添えます。

## 教材の作り直し

原本のMarkdownは `docs/kobun-vocabulary-source.md` に置いてあります。

```sh
python3 tools/import_kobun_vocabulary.py docs/kobun-vocabulary-source.md data/kobun-vocabulary.json
```

書き出したあと `npm test` を実行すると、語句数・重要度の内訳・範囲の並び・
アンダーラインの区間が用例にもどることを `tools/check-data.mjs` が確かめます。

## 範囲（作品）

一覧に収まるよう範囲名は短くし、カードの裏に出す `work` に正式な呼び名を残しています。

| 範囲名 | work |
| --- | --- |
| 伊勢物語 芥川 | 伊勢物語「芥川」 |
| 伊勢物語 東下り | 伊勢物語「東下り」 |
| 伊勢物語 筒井筒 | 伊勢物語「筒井筒」（第一部・結婚まで） |
| 徒然草 丹波に出雲 | 徒然草「丹波に出雲といふ所あり」（第236段） |
| 徒然草 花は盛りに | 徒然草「花は盛りに」（第137段・前半） |
| 羅生門 | 芥川龍之介『羅生門』（全文） |
| 今昔物語集 羅城門 | 今昔物語集 巻二十九第十八「羅城門登上層見死人盗人語」 |

原本の注記のとおり、範囲外（「これは、二条の后の…」「さて、年ごろ経るほどに…」
「片田舎の人こそ…」）の語句は収録していません。『羅生門』は青空文庫の本文を直接
確認できていないため、旧字・旧仮名の表記は教科書で確かめてください。
