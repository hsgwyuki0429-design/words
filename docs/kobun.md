# 古文の基礎暗記

古文は独立した教科です。`data/items.json` と既存3教科の出題処理には追加せず、専用のマスター・採点・画面で構成しています。

トップは上から助動詞、古文単語の順に配置します。古文単語は本文中の用例を使う自己採点カードなので、押すと他教科と共通の学習画面（範囲＝作品 → 重要度 → 並び替え → カード）へ渡します。助動詞を押すと5形式を同じ画面に表示し、他教科と共通の `mode-progress-card` と進捗バーのスタイルを使います。バーの薄い部分は形式別の解答済み問題数、濃い部分は直近の回答で完全正解した問題数です。古文には既存教科の習得周回判定を適用していないため、濃い部分の名称は「正解済み」と明示しています。回答回数や正答率を進捗の分母にしません。

助動詞一覧の折りたたみボタンは、基本形・活用型に加えて全意味を表示します。活用表は開いた内部に配置します。

## 初期教材

- 助動詞：添付「古文助動詞_活用表.xlsx」の28種類。
- 古文単語：定期テスト範囲7作品の重要語句360語句。トップから他教科と共通の学習画面へ渡します（[古文単語の重要語句](kobun-vocabulary.md)）。
- 助詞・敬語・文脈問題は今後の対象です。

助動詞は `data/kobun-auxiliaries.json` に収録しています。各項目に元のシート名・セル範囲・値を保持し、訂正・補足は `audit` に変更前後、理由、参照URLとページ番号を残しています。一覧画面でも確認できます。

参照：[三省堂の辞書付録「主要助動詞活用表」](https://www.kotomana-plus.net/dic-appendix/dk5/data/03_%E4%B8%BB%E8%A6%81%E5%8A%A9%E5%8B%95%E8%A9%9E%E6%B4%BB%E7%94%A8%E8%A1%A8.pdf)。

添付表からの主な訂正は「けむ」の接続、「めり」「なり（伝聞・推定）」の未然形、「たり（断定）」の接続、「たし」の補助活用です。「き」の特殊接続と「むず」の意味も補足しました。「き」の意味候補は「過去」に統一し、直接経験という説明を注記に分けています。その他は添付表の学習範囲を基本とし、まれな歴史的用法を一律に追加していません。

```sh
python tools/import_kobun.py 古文助動詞_活用表.xlsx data/kobun-auxiliaries.json
```

インポーターは今回の添付ファイルの行構成専用です。Pythonとopenpyxlが必要です。原本自体は変更せず、生成済みJSONは人が直接監査できます。

## マスターと問題生成

助動詞は `subject: "kobun"`、`category: "auxiliary"` と `kobun:aux:` 接頭辞の安定IDを持ちます。基本形が同じでも、断定の「たり」と完了・存続の「たり」などは別IDです。

`connections` と `meanings` は文字列配列、`conjugation` は6活用形それぞれの文字列配列です。活用なしは必ず空配列で保存します。画面と回答だけが「○」を使用します。

`src/kobun-logic.js` がマスターから問題を生成します。基本形識別では、表記と活用形名の組み合わせで全マスターを走査し、基本形の集合と関連する全助動詞IDを求めます。「せ・未然形」は「き／す」の2欄です。同じ基本形に複数の語義がある「たら・未然形」は基本形「たり」の1欄とし、解答後に該当する両方の助動詞を表示します。文脈なしで意味まで決めさせる問題にはしません。

将来範囲を絞る場合も、基本形識別の正解集合は全マスターから作成してから出題対象を絞ってください。候補の一部だけを正解にすることを防ぎます。

## 5形式と採点

| モードID | 操作・完全正解条件 |
| --- | --- |
| `kobun_connection` | 基本形から接続をすべて選択して一括回答。ラ変型の例外も選ぶ |
| `kobun_meaning` | マスターに存在する全意味候補から必要な意味をすべて選択 |
| `kobun_table_select` | 3列×2段の活用欄を選び、候補をタップして表を完成 |
| `kobun_table_input` | 6欄に直接入力。複数形は「／」で区切る。○専用ボタンは選択中の欄だけに入力 |
| `kobun_base_input` | 活用した表記と何形かを見て、表示された正解数と同じ数の欄に入力 |

すべて「回答する」を押すまで採点しません。意味は正しく選択・未選択・誤選択を個別に表示します。活用表は各欄ごとに正誤と正解を表示します。複数形のある活用欄も全形が必要で、順序は不問です。○と未回答を区別し、同じ形の重複で完全正解にはしません。

基本形識別は順序に依存しない集合比較です。正しい回答だけが一部ある場合は一部正解、誤答または重複があれば不正解です。「む／ん」のような基本形の別表記は同一の基本形として採点し、重複にも数えます。全意味・基本意味の難易度分離はありません。

意味問題の同形語は活用型で区別し、正解の意味を見出しに表示しません。接続・活用表では「なり（断定）」などマスターの区別名を表示します。

## 保存

既存のIndexedDBとlocalStorageフォールバックを使い、古文用IDで保存します。既存データの移行・削除は不要です。保存処理の失敗時はエラーを表示し、回答済みとして先に進めません。

- `history[itemId].modeStats[mode]`：回答数・正解数・不正解数・連続正解・時刻・回答時間。
- `modeStats[mode].lastAnswer`：教材リビジョン・入力値・個別の正解／不足／誤答／重複。
- `relatedItemIds`：基本形識別で関連する助動詞ID。後から助動詞別にも集計可能。
- `meta["kobunStudy:v1"]`：形式別の問題順・現在位置・未確定の入力・採点済み状態・今回の結果。

基本形識別は一意な「表記＋活用形名」を1問として記録し、他の4形式は助動詞1種類を1問として記録します。このため記録画面の問題数は形式ごとに異なります。

中断・リロード後は同じ形式から再開できます。採点済み画面を再表示しても二重記録しません。結果画面から間違いだけの復習か、同じ形式の学習を選べます。新しいセッションは未回答を先頭に、次に間違いを配置し、同じ状態の中はランダムに並べます。古文の途中状態は既存教科の周回キーと分離しています。

## 古文単語の追加

`data/kobun-vocabulary.json` の `items` に以下の形式で追加します。実際の教材を受け取ってから内容を監査してください。教材が空のときだけ、トップからは準備中画面が開きます。カードの作り・アンダーライン・ふりがな・生成手順は [古文単語の重要語句](kobun-vocabulary.md) にまとめています。

```json
{
  "id": "kobun:vocab:0001",
  "subject": "kobun-vocab",
  "category": "vocabulary",
  "headword": "女のえ得まじかりけるを",
  "reading": "おんなのええまじかりけるを",
  "meanings": ["自分のものにできそうもなかった女を"],
  "importance": "S",
  "range": "伊勢物語 芥川",
  "sources": []
}
```

助動詞と違い、古文単語は `subject: "kobun-vocab"` を持ちます。既存3教科と同じ出題処理・履歴・進捗を使うための教科IDで、画面上の呼び名は古文の中の「古文単語」です。

新しいカテゴリは `KOBUN_CATEGORIES` と専用の教材・出題処理を追加して拡張できます。英語の `english` / `japanese` フィールドへの変換は不要です。

`npm test` にマスターの整合性、全意味採点、複数接続、○と未回答、複数形、逆引きの曖昧性・重複・順不同、形式別集計、途中状態の復元を追加しています。アプリの更新時は `sw.js` のキャッシュと新モジュール・教材のバージョンも揃えてください。
