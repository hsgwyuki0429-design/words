# 効果音の設計

カードをめくる・答える・ボタンを押すときの効果音の設計メモです。実装は `src/sfx.js`、測定の道具は
`tools/measure-sfx.mjs`、テストは `test/sfx.test.mjs` にあります。

いちばん大事にしたのは「何度聞いても気持ちよく、もう一度聞きたくなること」です。音の選び方・作り方・
大きさ・出し方のすべてを、この目的に合わせて決めました。

## 鳴る場面

| 場面 | 音 | 備考 |
| --- | --- | --- |
| フラッシュカードを答え面へめくる | 紙が擦れる「サッ」→ カードが落ち着く音（10種からレア度つきの抽選） | 「サッ」の山のすぐあと（75ms後）に落ち着く音を重ねる |
| 問題面へ戻す | 紙の音だけ（下がる向き） | ごほうびの抽選はしない |
| カードを払って次へ（フラッシュカード・4択・入力） | カードが紙の上をすべる音 | 払った方向へ音も動く。払いかけて戻したときは鳴らない |
| 4択・入力で正解 | 正解の音（10種からレア度つきの抽選） | 保存を待たずに、押した瞬間に鳴らす |
| 4択・入力で不正解 | 不正解の音（1種） | 正解の音と同じ「木」の世界のまま、低く・こもらせる |
| 答え合わせ済みの4択（公共）を裏返す | 紙の音だけ | |
| ボタン | ごく小さな雫の「ぽっ」 | その操作でほかの音が鳴ったときは重ねない |
| 設定のスイッチ | 入れると上がる2音、切ると下がる2音 | |
| アプリ内の英字キーボード | ボタンより小さく短い「コッ」。打つたびに近い4つの音程から選ぶ | 消すキーは低い音 |
| 古文の問題の正誤 | 正解・不正解の音 | |

フラッシュカードの自己採点（払う）には正誤の音を付けず、すべる音だけにしています。自分で付けた採点に
「正解」「不正解」の音を返すと、評価されているように感じてしまうためです。

## 水の音にそろえた理由

最初は木・ガラス・石など素材の違う音を並べましたが、使ってみていちばん気持ちよかったのが水滴の音でした。
そこで、紙の音を除くすべての音を、耳元で聞く ASMR のような水の音にそろえました。

水滴が水面に落ちると、水の中に小さな泡ができ、その泡が一瞬で縮むので共鳴の高さが急に上がります。
これが「ピチョン」「ポコッ」の正体です。この「高さが上がる正弦波」を土台に、上がり方（ピチョン⇔ポコ）・
長さ・残響・重ね方を変えて、系統の違う音を作っています。ボタン・スイッチ・キーもごく小さな雫、
不正解だけは泡を下がらせた「ポコ…ポコ↓」です。

## 正解の音（10種）

すべて明るく、協和する音程へ上がっていく水の音です。下へ行くほど豪華で、出にくくしてあります。

不正解の音は1種類です。同じ水の世界のまま、低い泡が2つ、こもって下がります。

## 心地よさのために決めたこと（根拠つき）

### 1. 毎日聞いている「物の音」にする

身の回りの物がたてる音は、学ばなくても意味が分かり、自然に聞こえます（Gaver の auditory icons）。
そこで電子音ではなく、紙と水の音にしました。

物の音は、その物が持つ固有の振動（モード）の重ね合わせです。それぞれのモードを「減衰する正弦波」で作り、
足し合わせています（モード合成）。人は素材の違いを、主に音の減衰の速さで聞き分けます（Klatzky ら）。
小さな雫は速く消え、洞窟の雫や水琴窟は長く響くように、場面ごとに減衰の時間を決めています。
水の音は、泡の共鳴の高さが一瞬で上がる動き（ピチョン）を土台にし、上がり方・長さ・残響で「小さな雫」「泡」「小瓶」「洞窟」などを描き分けています。

### 2. 耳に刺さる帯域を避ける

不快に感じる音は、2.5〜5.5kHz の帯域に強いエネルギーがあることと結びついています（Kumar ら）。
心地よさは、うるささ（大きさ）・鋭さ（高い音の多さ）・粗さ（速い揺れ）が増えると下がります（Zwicker & Fastl）。

- 高い倍音は弱く、短くしています。測ると、紙の音以外は 2.5〜5.5kHz のエネルギーが全体の1%未満です
- 出口でも 3.6kHz を中心にすこし（-4dB）下げ、11.5kHz より上を丸めています
- 紙の音はこの帯域を避けられない（紙の音らしさそのもの）ので、中心を 1.2〜2.5kHz に置き、帯域の外を削って小さめにしています

### 3. 紙の音は「パリッと」させる

食べ物をかじる音の高い成分を強めると、同じポテトチップスでもパリッと新鮮に感じます（Zampini & Spence）。
音は手ざわりの感じ方を変えます。紙の音には、紙の繊維がこすれる細かい「プチプチ」を混ぜた雑音を使い、
6.5kHz より上の空気感をほんの少しだけ足して、乾いた紙の手ざわりにしました。

### 4. 濁らせない

近い高さの音が重なると、うなりが速くなって濁ります（Plomp & Levelt）。
すべての音程を C メジャー・ペンタトニック（ド・レ・ミ・ソ・ラ）にそろえ、半音や増4度を作らないようにしました。
どの音どうしが重なっても（めくった直後に正解の音が鳴っても、MAX のコンボの音と重なっても）濁りません。
MAX の音も同じ音階なので、MAX と一緒に鳴っても調和します。

水琴窟などでは、わざと2つの振動をわずかにずらして揺らしていますが、揺れは毎秒1〜4回の
ゆっくりしたものだけです。濁りを生む速い揺れの帯域（毎秒十数回〜）には入れていません。

### 5. 大きくしない。レアは音量ではなく豊かさで

大きい音は心地よさを下げ、驚かせます。ふつうの大きさでも控えめにし、レアな音を大きくすることはしていません。
代わりに、レアな音ほど響き（残響）・左右の広がり・余韻・音の数を豊かにしています。

### 6. いつ来るか分からないごほうびにする

ごほうびが出るかどうか分からないとき、脳のドーパミン神経は「期待」の段階から反応し、その反応は不確かさが大きいほど
強くなります（Fiorillo, Tobler & Schultz）。音楽でも、山場を待つ間と山場そのものとで、別々にドーパミンが
放出されます（Salimpoor ら）。予想より良いことが起きたときの驚きは、予想どおりの良いことより気持ちよく感じられます（Huron）。

そこで、めくった音と正解の音をレア度つきの抽選にしました。

- ふだんはコモン（めくった音は58%、正解の音は58%）。くり返し聞くうちに耳になじみ、なじんだ音は好きになりやすい（Zajonc の単純接触効果）
- ときどき（約3回に1回）アンコモン、約8回に1回レア以上、約33回に1回激レア以上、100回に1回伝説
- 50回正解するあいだに伝説の正解の音が出る見込みは約4割。忘れたころに来るくらいにしています（めくった音は別に抽選します）

### 7. 慣れさせない

同じ音をまったく同じに鳴らし続けると、耳が慣れて飽きます（なじみすぎると好ましさが下がることも知られています）。
ゲームの音づくりでは、毎回少しずつ変えるのが定石です。どの音も毎回、音程を ±12セント、強さを ±0.5dB ほど、
紙の音は長さと高さもわずかに変えています。英字キーボードは打つたびに近い4つの音程から選びます。
どれも気づかないほど小さな変化ですが、くり返しの単調さを消します。

### 8. 指の動きから遅れない

タッチ操作への音の返事は、20〜70ms 以内だと質が高く感じられます（Kaaresoja, Brewster & Lantz）。
音は描画や保存を待たずに、操作を受けた瞬間に予約します（先読みは 5ms）。最初の操作で音の仕組みを準備しておき、
1回目の音から遅れないようにしています。

### 9. 正解と不正解は、はっきり違うが、同じ世界の音にする

正解は明るく、高く、協和する音程で着地します。とくに主音（ド）へ終わる形は「終わった」という落ち着きがあります。
「ピンポン」（ミ→ド）は下がりますが、日本ではクイズの正解の合図としてなじみがあるので入れました。

不正解は、同じ木の素材のまま、低く・こもらせ・下がる2音にしました。ブザーのような濁った音は使いません。
間違いを罰する音は緊張を高め、学ぶ気持ちを下げるおそれがあるためです（音そのものを比べた研究は見つかりませんでしたが、
否定的なフィードバックが不安を高めるという報告はあります）。「上がる音程は良い、下がる音程は悪い」という対応は、
研究によって結果が分かれるので、音程の向きだけに頼らず、高さ・明るさ・こもり方の違いでも区別しています。

### 10. スマホのスピーカーでも同じように聞こえる

スマホの小さなスピーカーは、約500Hz より低い音がほとんど出ません。低い音（不正解・木・フェルト）は、基音のほかに
2〜4倍の倍音を持たせました。基音が出なくても、耳は倍音から元の低い音程を補って聞きます（ミッシング・ファンダメンタル）。

## 大きさのそろえ方

`tools/measure-sfx.mjs` で、全32種の音を Chromium の OfflineAudioContext に書き出して測り、`SFX_LEVELS` を決めました。

- 測る大きさ：K特性（ITU-R BS.1770）で重みづけし、100ms ごとの大きさの最大をとったもの
- スマホ相当：同じ測り方で、600Hz より低い音を急に落としたもの
- 合わせ方：この2つの平均が、種類ごとの目標になるまでくり返し補正

| 種類 | 目標（ふつうの大きさ） |
| --- | --- |
| 正解 | -18 |
| めくった音 | -22（フェルトだけ -23） |
| 不正解 | -22（正解より小さく、やさしく） |
| 紙の音 | -26 |
| すべる音 | -27 |
| ボタン・スイッチ | -27〜-28 |
| キー | -31 |

余韻が長い音（水琴窟・洞窟の雫）は、存在感が大きいのでさらに 1dB 下げています。
ピークはふつうの大きさで -6dBFS 以下です。出口にはリミッターと、-0.9dBFS で頭をなめらかに丸める段を置き、
いくつ重なっても割れないようにしています。

## しくみ

- 音声ファイルは持たず、Web Audio でその場で合成します（オフラインでも動き、通信量も増えません）
- 出口までのつなぎ：声 → 80Hz より低い音を切る → 3.6kHz をすこし下げる → 高域を丸める → 音量 → リミッター → 頭を丸める → 出口
- 残響：小さめのホール（約1秒）を合成して使います。高い音から先に消えていくようにしてあります
- 同時に鳴る音は14まで。超えたら古い音から素早く消します
- 20秒鳴らさなければ、電池のために音声の処理を止めます。画面を離れたときも止めます
- 設定の「効果音」（初期設定はオン）と「効果音の大きさ」（小さめ・ふつう・大きめ）は、SIMPLE・MAX のどちらでも使えます
- MAX の「MAXの演出音」は別の設定です。両方オンのときは、正誤そのものの音は効果音が鳴らし、MAX はコンボ・大当たりなどの節目の音だけを重ねます
- iPhone では、消音モード（サイレント）のとき、Web Audio の音はふつう鳴りません（端末の設定に従います）

## 聞き比べ・調整のしかた

アプリを `?sfx-lab` を付けて開くと、画面の下に「効果音ラボ」が出ます。押して開くと、すべての音を1つずつ、
レア度と確率つきで鳴らせます（ふだんの画面には出ません）。

```text
https://（アプリのURL）/?sfx-lab
```

音を変えたときは、次で測り直せます（Playwright と Chromium が必要。アプリの実行やテストには不要です）。

```sh
node tools/measure-sfx.mjs                      # 一覧
node tools/measure-sfx.mjs --wav out/wav        # WAV に書き出して試聴
node tools/measure-sfx.mjs --png out/png        # スペクトログラムの画像
node tools/measure-sfx.mjs --only correct-harp  # 1つだけ
```

- 出る確率を変える：`LANDING_VARIANTS` / `CORRECT_VARIANTS` の `weight`（合計を1にする。テストで確かめています）
- 大きさを変える：`SFX_LEVELS`（測って、種類ごとの目標にそろえる）
- 音そのものを変える：`SOUNDS` のレシピ。音程は `NOTE_MIDI` にある音（ペンタトニック）だけを使う
